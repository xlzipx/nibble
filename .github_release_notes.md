**Nibble** — capture, trim and share only what you need.
Everything for quick clips on Windows: screenshots and screen recordings with
drawing tools, video downloads from YouTube, X and 1000+ sites, trimming with a
live preview and compression that fits Discord.

## Download
- **Nibble-Setup-v1.0.0.exe** — recommended installer (current user, no admin)
- **Nibble-Portable-v1.0.0.exe** — portable, no install: keeps everything in a `Nibble Data` folder next to itself

## Install
1. Download and run the `.exe` (or just start the portable version)
2. Windows SmartScreen may warn "Unknown publisher" — click **More info → Run anyway** (the app isn't code-signed)
3. On first launch a short setup check installs ffmpeg / yt-dlp if they're missing — one click, no PATH changes

## Features
- **Screen capture** — screenshots (Ctrl+Shift+A) that snap to windows and their parts, with drawing tools (shapes, arrows, text, blur, pixelate); PNG / JPG / WebP
- **Screen recording** — MP4 or GIF (Ctrl+Shift+R) with system sound or mic, countdown and safety limits; works correctly on HDR displays
- **Download from URL** — YouTube, X, Reddit, TikTok and 1000+ sites; trim a section and only that part is downloaded
- **Quick share** — paste a link, the clip lands on your clipboard, ready for Ctrl+V; the temp file deletes itself
- **Fit for Discord** — compresses to 20 / 50 / 500 MB automatically
- **Trim** with a live preview and frame-exact cuts
- **Convert** to H.265 / H.264 with the best encoder for your PC (NVIDIA NVENC, AMD AMF, Intel QSV, CPU fallback)
- **HDR → SDR** tonemapping for Shadowplay captures (After Effects-ready presets)
- **Watch folder** — new clips are converted automatically
- Clean uninstall — leaves no files or registry entries behind
